# 客服 AI 助手（kefu）

给跨境电商客服用的本地 AI 助手：把客户发来的文字或截图粘贴进来，AI 结合你的资料库、话术和历史成交记录，写出标准的英文回复（附中文翻译），并推荐该发哪张图、哪个视频。

- **单文件运行**：Windows / macOS / Linux 一个可执行文件，双击打开，界面在浏览器里，不需要安装数据库或运行环境。
- **数据全在本地**：资料、客户、聊天记录都存在程序旁边的 `kefu-data/`。
- **本地模型优先**：默认用 [Ollama](https://ollama.com) 跑本地模型，也可以接任何 OpenAI 兼容的云端模型（阿里云百炼、DeepSeek、OpenAI…）。

> 这是一个“副驾驶”工具：AI 只给建议，由客服确认后再复制到 WhatsApp 等聊天软件里发送。目前不直接接入聊天平台。

## 功能

| 模块 | 说明 |
|---|---|
| 💬 接待工作台 | 每个客户独立会话；粘贴文字或截图（Ctrl+V）；AI 给出意图、情绪、风险提醒、把握度、英文回复 + 中文翻译；一键采纳、改写、换说法、中文写好再翻译 |
| 🧠 客户画像 | 根据聊天自动总结客户阶段、购买意向、顾虑、沟通风格和下一步建议 |
| 📚 资料库 | Excel（含加密、合并单元格）、Word、PPT、PDF、CSV、TXT、HTML、图片，没有后缀的文件按内容识别；历史聊天记录单独导入作为话术参考 |
| ✍️ 自定义话术 | 不用上传文件，直接写“遇到什么情况 → 怎么回”，AI 优先使用；聊天里的好回复可一键存为话术 |
| 🖼️ 素材库 | 实拍图、视频、物流凭证、好评截图；AI 自动看懂内容、总结“什么时候发”，回复时推荐附带哪个素材 |
| 🔍 问一下 AI | 像客户一样提问，同时查资料库、话术和素材库；资料库没有的通用知识可联网查 |
| 🌐 联网搜索 | 大模型自带联网（百炼）、博查、Ollama、Tavily、SearXNG、DuckDuckGo；只用于通用知识，绝不用于价格、库存、订单等店铺信息 |
| 📊 统计 | AI 采纳率、修改率、客户都在问什么 |
| 💾 备份与升级 | 一键完整备份（含图片视频）；升级后首次启动自动备份数据库 |

## 快速开始

### 1. 准备模型（本地）

在有显卡的电脑上安装 [Ollama](https://ollama.com/download)，然后：

```sh
ollama pull qwen3:14b              # 对话（16GB 显存；显存小可用 qwen3:8b）
ollama pull qwen3-vl:8b-instruct   # 看图：截图识别、素材识别
ollama pull bge-m3                 # 向量：按意思检索资料
```

Ollama 装在另一台电脑上也可以：那台电脑设置环境变量 `OLLAMA_HOST=0.0.0.0` 后重启 Ollama，本程序里填它的局域网地址，如 `http://192.168.1.20:11434`。

不想用本地模型，可以在「设置 → 云端大模型」填写阿里云百炼、DeepSeek 等的接口地址和 Key。

### 2. 运行

从 [Releases](https://github.com/git-ljm/kefu-ai/releases) 下载对应系统的文件（或自己编译，见下文），放到一个固定的文件夹里双击运行：

- Windows：`kefu-windows.exe`（首次运行如被 Windows Defender 拦截，点“仍要运行”）
- macOS：`kefu-mac`（首次打开右键 →「打开」）

浏览器会自动打开 `http://127.0.0.1:8686`。先到「⚙️ 设置」点「测试连接」，三个模型都显示 ✅ 就可以用了。

### 3. 使用

1. 「📚 资料库」拖入产品表、政策文档、历史聊天记录；在「✍️ 自定义话术」写常用答法
2. 「🖼️ 素材库」拖入可以发给客户的图片和视频
3. 「💬 接待工作台」新建客户 → 粘贴客户消息或截图 → 「AI 分析并写回复」→ 采纳并复制 → 到聊天软件里粘贴发送

## 配置说明

所有配置都在网页「⚙️ 设置」里，保存后立即生效。

| 项目 | 默认 | 说明 |
|---|---|---|
| 本地对话 / 看图 / 向量模型 | `qwen3:14b` / `qwen3-vl:8b-instruct` / `bge-m3` | Ollama 模型名 |
| 云端大模型 | 关闭 | 任何 OpenAI 兼容接口；看图模型名留空则看图仍用本地 |
| 向量模型 | 本地 Ollama | 也可用云端，如百炼 `text-embedding-v4`、`qwen3.7-text-embedding`。**换向量模型后会自动在后台重建全部向量** |
| 回复语言 | 固定英文 | 也可“跟随客户语言” |
| 联网搜索 | 关闭 | 见下文 |

### 联网搜索怎么选

| 方式 | 适合 | 需要 |
|---|---|---|
| 大模型自带联网 | 已经在用阿里云百炼的 Qwen 模型 | 只需「云端大模型」配置好百炼，不用另外申请 |
| 博查 | 国内网络，想要搜索结果列表和来源链接 | 博查 API Key |
| Ollama / Tavily | 海外网络 | 对应 API Key；国内一般要填代理 |
| SearXNG | 想完全自己掌控 | 自己部署 SearXNG（开启 JSON 输出） |
| DuckDuckGo | 免费试用 | 国内需要代理，且容易被限流 |

**本地 Ollama 模型自己不能上网**：模型只会生成文字，联网要由程序先搜索、再把结果交给模型。所以选本地模型时，请用博查等搜索服务。

## 工作原理

```
导入资料 ──► ETL 解析成文本片段（每段约 700 字；表格按行，带表头）
          ──► 向量模型把每段变成一串数字（向量），存进 SQLite
客户消息 ──► 同样变成向量 ──► 混合检索：
             · 向量余弦相似度（按“意思”找，换个说法也能找到）
             · 关键词加分（订单号、型号等带数字的词精确命中直接排最前；中文按二字词匹配）
          ──► 分别取最相关的：自定义话术 3 条、资料 6 条、历史成交 3 条、示范回复 3 条、素材 5 个
          ──► 连同客户画像、最近 16 条对话一起交给对话模型，按规则生成 JSON：
              意图 / 情绪 / 风险 / 回复 / 翻译 / 把握度 / 需要客服确认的信息 / 推荐素材
```

- 全部片段常驻内存逐条打分，几万个片段以内是毫秒级，不需要单独的向量数据库。
- 向量模型不可用时自动退化为纯关键词检索，页面会提示。
- 每个向量都记录了是哪个模型生成的；换了模型或维度，旧向量会作废并后台重建，避免不同模型的向量混用。
- 客服修改过的回复会自动存为“示范回复”，之后优先模仿，越用越贴近你们的说话方式。

## 数据、备份与升级

```
kefu-data/
├── kefu.db          数据库：设置、资料片段与向量、客户、聊天记录
├── files/docs/      导入的原始资料
├── files/img/       客户截图
├── files/media/     素材图片和视频
└── backups/         升级时自动生成的数据库备份（保留最近 5 份）
```

- **升级**：关闭程序 → 用新的可执行文件覆盖旧的（放在同一文件夹）→ 重新打开。数据库结构会自动迁移。
- **备份**：「设置 → 数据存放与备份」可下载完整备份（zip，含图片视频）或只备份数据库。
- **换电脑**：把程序和整个 `kefu-data/` 一起拷过去。
- 重复打开程序不会启动第二个，会直接打开已经在运行的页面。
- 不要把 `kefu-data/` 放在网盘同步目录里让多台电脑同时使用。

## 安全与隐私

- 程序默认只监听 `127.0.0.1`，**没有登录功能**。请不要用 `-host 0.0.0.0` 暴露到局域网或公网。
- 使用云端模型时，客户消息和检索到的资料片段会发送给云端服务商；使用云端向量模型时，资料库内容会发送给服务商。
- 联网搜索发出的是 AI 提炼后的关键词，会去掉客户姓名、订单号、联系方式。
- API Key 保存在本地数据库，页面上只显示 `********`。
- 加密 Office 文件的密码只在导入时使用，不会保存；但解密后的内容会以明文存在 `kefu.db` 里，请按资料本身的保密级别保管数据目录和备份。

## 开发

需要 Go 1.26+（依赖库的最低要求）。

```sh
git clone https://github.com/git-ljm/kefu-ai.git
cd kefu-ai
```

前端是原生 HTML/CSS/JS，没有构建步骤，修改后重新编译即可（页面通过 `go:embed` 打包进程序）。

```sh
make run          # 开发运行（数据在 ./kefu-data）
make test         # 单元测试 + 接口测试（使用模拟模型，不需要 Ollama）
make vet          # 静态检查（含 Windows）
VERSION=1.2.0 make dist   # 打包 Windows / macOS / Linux 到 dist/
```

浏览器端到端测试见 [tests/e2e/README.md](tests/e2e/README.md)。

### 目录结构

```
cmd/kefu/            程序入口：命令行参数、单实例、启动 HTTP 服务
internal/
  instance/          单实例锁、数据目录定位（程序被移动后仍能找到原数据）
  store/             SQLite 存储（纯 Go，无需 CGO）
  llm/               模型调用：Ollama / OpenAI 兼容接口的对话、看图、向量
  etl/               文件解析：各种格式 → 文本片段；文件类型识别；视频截帧
  rag/               内存混合检索（向量 + 关键词）
  websearch/         联网搜索服务适配
  server/            业务逻辑与 HTTP 接口（导入、回复建议、画像、素材、话术、问答、备份）
web/static/          前端页面
tests/e2e/           浏览器端到端测试脚本
scripts/build.sh     多平台打包
```

### 主要依赖

[modernc.org/sqlite](https://gitlab.com/cznic/sqlite)（纯 Go SQLite）、[excelize](https://github.com/xuri/excelize)（Excel，含解密）、[ledongthuc/pdf](https://github.com/ledongthuc/pdf)（PDF 文本）、[golang.org/x/text](https://pkg.go.dev/golang.org/x/text)（GBK 编码）。
