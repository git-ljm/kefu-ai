# 浏览器端到端测试

用本机 Chrome（无头模式）+ Node 自带的 WebSocket 驱动页面，不需要安装任何 npm 依赖。需要 Node 22+ 和 Google Chrome。

先用一个**测试数据目录**启动程序（脚本会写入测试客户和话术，不要指向真实数据）：

```sh
go run ./cmd/kefu -no-browser -port 8698 -data /tmp/kefu-e2e
```

再运行对应脚本：

| 脚本 | 测试内容 | 前置数据 |
|---|---|---|
| `e2e.mjs` | 打开客户 → 粘贴消息 → AI 建议 → 采纳 → 刷新后仍停留在该客户 | 至少 1 个客户，需要可用的模型（或模拟模型） |
| `autofill.mjs` | 浏览器自动填充不会把客户搜索框“填空” | 至少 2 个客户 |
| `snippet.mjs` | 自定义话术新增 / 编辑 / 从聊天“存为话术” | 客户 1 有一条我方回复 |
| `ask.mjs` | 「问一下 AI」、素材打通、联网搜索设置 | 已配置联网搜索 |

```sh
node tests/e2e/autofill.mjs http://127.0.0.1:8698
```

Go 单元测试和接口测试（含模拟模型）直接运行 `go test ./...`。
