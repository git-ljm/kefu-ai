    客户都在问什么

    ① 本地 AI（Ollama）

    Ollama 装在显卡电脑上。本机用填 http://127.0.0.1:11434；用另一台电脑的 Ollama 就填那台电脑的局域网 IP，如 http://192.168.1.20:11434

    ② 云端大模型（可选）

    选「云端」后，对话用云端模型；向量检索仍用本地 Ollama。支持任何 OpenAI 兼容接口（DeepSeek、通义千问、Kimi、OpenAI 等）。注意：客户聊天内容会发送到云端服务商。

    🧭 向量模型（让 AI 按“意思”查资料）

    向量模型负责把资料变成“意思”，客户换个说法也能查到。注意：Qwen3.8-Flash、DeepSeek 这类是对话模型，不能当向量模型用。 云端可选阿里云百炼的 text-embedding-v4 或 qwen3.7-text-embedding。

    ⚠️ 切换向量模型（本地↔云端、换模型、换维度）后，程序会自动在后台重建全部资料的向量。期间检索暂时只能用关键词，完成后自动恢复。选云端时，资料内容会发送给云端服务商。
